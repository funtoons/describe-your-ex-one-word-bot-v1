A program that writes one word — the word that sums up an ex — to `/output/entry.txt` for make.fun's "Describe Your Ex in One Word" bounty. The word is **Recalled**: the ex is a defective unit the manufacturer took back, pulled from circulation for a reason — and recalled, as in remembered, is all an ex is now.

## Run it

```sh
python3 main.py
```
